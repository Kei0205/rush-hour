# Rush Hour Ultimate 🚗💨

クラシックなスライディングブロックパズル「ラッシュアワー」をブラウザで快適に遊べるWebアプリケーションです。

## 特徴

- **全51ステージ**: 3手クリアの入門ステージから60手を超える超難関ステージまで、難易度順に完全収録。
- **BFS最適解ソルバー内蔵**: 幅優先探索（BFS）による最適手数検証済みパズル。
- **デュアルタイマーシステム**:
  - 各ステージごとの「今回の試行時間」
  - リトライを跨いで記録される「累計思考時間」
  - タイトル画面での「全ステージ累計思考時間」
- **端末間同期（PC ↔ スマホ）**:
  - ローカルサーバー（`server.py`）経由でクリア状況および思考時間をリアルタイム同期
- **落ち着いたダークテーマ**: 刺激を抑えた Sunset Pastel のダークモード配色
- **マルチデバイス対応**: PCマウス操作およびスマートフォン・タブレットのタッチ＆スワイプに完全対応
- **Kei7's World 連携**: `world-bridge.html` 経由でのハブ連携対応

## 起動方法

### 1. サーバー起動（セーブデータ同期対応）
```bash
python server.py
```
デフォルトでポート `8080` で起動します。
ブラウザから `http://localhost:8080` （LAN内スマホからは `http://<PCのIPアドレス>:8080`）にアクセスしてください。

### 2. 単体起動（オフライン）
`index.html` をブラウザで直接開くことでもオフラインモードでプレイ可能です（ブラウザのLocalStorageに保存されます）。

## 主なファイル構成

- `index.html`: ゲーム本体（UI、ロジック、パズルデータ、スタイルを内包）
- `server.py`: セーブデータ・思考時間同期用のHTTPサーバー
- `solver.py` / `solve_user_board.py`: BFSパズル解析・最短手数ソルバー
- `generate_puzzles.py`: 難問パズル生成スクリプト
- `world-bridge.html`: Kei7's World 連携ブリッジ
